# 2ª Avaliação - Tecnologia para Frontend Avançado

Trabalho prático da disciplina de Tecnologia para Frontend Avançado.

## Equipe

- Hélio Siqueira
- Pedro Felipe
- Sabrina Holanda

Aplicação web desenvolvida com React, TypeScript e Vite, com foco em:

- Componentização
- Hooks
- Rotas
- Consumo de API

## Tecnologias utilizadas

- React
- TypeScript
- Vite
- Material UI
- Context API
- React Router
- API RemoteOK

## Sobre o projeto

O projeto consiste em um hub de vagas de estágio, onde estudantes podem:

- Filtrar vagas por modelo de trabalho (remoto, híbrido ou presencial)
- Visualizar atribuições e requisitos das vagas
- Gerenciar vagas favoritas
- Realizar candidaturas fictícias
